# Embedded C Programming

This section demonstrates practical Embedded C programming concepts, memory management techniques, low-level programming, and firmware-oriented implementations.

The objective is to demonstrate how Embedded C concepts are applied in resource-constrained microcontroller environments.

## Topics Covered

### 1. Pointers and Memory
- Pointer fundamentals
- Pointer arithmetic
- Pointer to pointer
- Arrays and pointers
- Function pointers
- Memory address manipulation

### 2. Memory Management
- Stack and heap
- Static and global memory
- Memory allocation
- Memory alignment
- Memory optimization
- Buffer management

### 3. Bit Manipulation
- Set, clear, toggle and read bits
- Bit masks
- Register manipulation
- Shift operations
- Bit fields and their limitations

### 4. C Qualifiers and Storage Classes
- volatile
- const
- static
- extern
- Register access and compiler optimization

### 5. Structures and Unions
- Structure padding
- Alignment
- Unions
- Memory-efficient data representation

### 6. Function Pointers
- Callback mechanisms
- Function pointer arrays
- Driver abstraction
- Interrupt callback concepts

### 7. Circular Buffer
- FIFO implementation
- Buffer wraparound
- Full and empty conditions
- Producer-consumer model

### 8. State Machines
- Finite state machine implementation
- Event-driven design
- State transitions
- Error handling

## Engineering Focus

Each implementation aims to demonstrate:
- Readable and maintainable code
- Memory-efficient programming
- Predictable behavior
- Boundary-condition handling
- Embedded firmware applications
- Testing and debugging

## Development Environment

- Language: C
- Compiler: GCC
- Platform: Linux / WSL2
- Target: Embedded systems and ARM microcontrollers
